# 전포 가전 안내 자료 확인 기록

확인일: 2026-11-13. 공유 숙소정보 문서의 최신 가전 목록을 반영했다. 문서의 비공개 비밀번호는 공개 소스에 포함하지 않았다.

## 참고 사이트와 맞춘 기능

어나더하우스·스테이네모의 기기별 이미지 넘김, 이전·다음, 페이지 수, 그림 확대, 사용 순서, 제조사 설명서 연결 흐름을 전포의 가전 12종 및 세탁·건조 2종에 적용했다. 안내 그림은 투숙객의 기본 조작을 정리한 자체 도식이며 제조사 원본 그림과 구분해 표기한다.

## 관광 사진

관광지 20곳 모두 부산관광아카이브 공공누리 제1유형 사진을 사용한다. 사진 위 출처 문구는 제거하고, 필요한 제작자·제공기관·원문 링크를 페이지 하단의 접이식 `사진 출처`에 모았다. 원본 비율·색상은 유지하고 WebP 변환 및 크기만 조정했다. 전체 출처는 `local-photo-credits.json`에 기록했다.
